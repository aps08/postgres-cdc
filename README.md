# Postgres CDC

This repository contains the companion code for the article: **[How to Master Postgres CDC: Setting Up Real-Time Data Streaming](https://medium.com/@aps08)**.  It provides a fully containerized sandbox demonstrating how to stream real-time database mutations from PostgreSQL to an Apache Kafka event broker using Debezium Connect (Logical Replication) and consumer logs.  For the step-by-step setup and operational guides, please refer to the complete article link above.
